# 🐦 猜猜Bird —— 鸟种识别大挑战

> 基于《郑光美 第四版》1508 种中国鸟类名录，三关挑战你的鸟类分类知识！  
> 清新自然风 · 零依赖 · 单文件即玩 

---

## 🎮 游戏预览

| 🦅 第一关 · 识目大师 | 🐦 第二关 · 辨科高手 | 🛡️ 第三关 · 保护级别 |
|:---:|:---:|:---:|
| 10 题 | 10 题 | 16 题 |
| 给鸟名 → 选**目** | 给鸟名 → 选**科** | 给鸟名 → 选**保护级别** |
| 4 选 1 | 4 选 1（已过滤科名提示） | 一级 / 二级 |

---

## ✨ 亮点功能

- 🌿 **清新自然 UI** — 毛玻璃卡片、浮动树叶动画、绿色渐变背景
- ❤️ **我想看清单** — 答题时点爱心收藏想看的鸟，结束后一键导出 `.txt` 鸟单
- ⬅️ **上一题回看** — 随时退回查看已答题目，再一键回到当前进度
- ⚡ **答对自动跳转** — 无需手动点下一题，行云流水的答题体验
- 🔁 **智能去重** — 再来一局时优先出没见过的鸟，第二关自动过滤科名暗示题
- 🏆 **猜猜Bird大师** — 90 分以上触发金色绶带 + 全屏彩纸飘落颁奖典礼
- 📱 **手机适配** — 响应式设计，随时随地来一局

## 🛠️ 技术栈

纯静态网页，零依赖，零构建：

| 层 | 技术 |
|----|------|
| 结构 | HTML5 |
| 样式 | CSS3（渐变、毛玻璃、关键帧动画） |
| 逻辑 | 原生 JavaScript（ES5 兼容） |
| 存储 | sessionStorage（去重持久化） |

所有 1508 条鸟类数据直接内嵌在 `<script>` 标签中，离线也能玩。
